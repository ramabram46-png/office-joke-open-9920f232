A program that writes one line of office comedy to `/output/entry.txt` — one joke about office life, under 200 characters. Entry for the
[make.fun bounty "Make the AI Judge Laugh: the Office Joke Open"](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232).

## The joke

> Someone keeps stealing lunches from the office fridge, so HR put up a sign: 'Please do not steal lunches.' The thief signed it.

## Run

```sh
node main.ts
```

`main.ts` (Node 22) writes the joke above, exactly, to `/output/entry.txt`.
No network.
